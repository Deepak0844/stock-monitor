# Project rules: skills are mandatory

Skills live in `.claude/skills/`. On EVERY prompt in this repo, before doing anything:

1. Invoke `using-superpowers` (obra/superpowers) and follow its process skills
   (brainstorming, writing-plans, test-driven-development, systematic-debugging,
   verification-before-completion) as they apply.
2. Apply `caveman` (terse responses) and `ponytail`.
3. Apply `karpathy-guidelines` and `using-agent-skills` (addyosmani) for engineering workflow.
4. Use `graphify` for codebase understanding/knowledge graph when exploring code.
5. For any UI/frontend work, invoke `ui-ux-pro-max` and `design-taste-frontend` (taste-skill).

If a skill might apply even slightly, invoke it via the Skill tool first.
